# Jeremy Cheng — Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8080` in this folder and visit http://localhost:8080.

## Edit
- `index.html`: biography, projects, experience, education and email.
- `styles.css`: layout, colours and responsive design.
- `script.js`: mobile navigation and footer year.
- `assets/`: portrait and favicon.

Project summaries expand using native HTML details elements and remain usable without JavaScript.

## GitHub Pages
Publish the `main` branch from `/ (root)` in Settings → Pages → Deploy from a branch. Keep `.nojekyll` at the root. Relative asset URLs support both account and project sites.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Content
Professional project summaries are based on the supplied resume and employment reference. Education and academic honours are based on the supplied university records. Official NCHU degree names are used. The WWU position is presented as a functional description over the full employment period because the resume and reference use different title breakdowns. AI experience is described as academic study, not invented project work.

Source PDFs, phone numbers, student numbers, birth date, signatures and referee details are not included. The contact email and supplied portrait are intentionally part of the public website. Add verified project screenshots or repository links when available.

Public AI project summaries and links were read from the three corresponding public GitHub READMEs. No benchmark results, personal contribution breakdowns, or production claims are inferred.
